# Service Center — ИС управления заявками

## Описание
Минимально жизнеспособная информационная система для приёма и обработки
заявок в сервисный центр. Реализован полный поток:
регистрация → авторизация → работа с заявками.

## Стек технологий
- **Backend:** PHP 7.4+ (чистый, без фреймворков)
- **База данных:** MySQL 8.x
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Сервер:** Apache (XAMPP)
- **СУБД-клиент:** MySQL Workbench, phpMyAdmin

## Сущности базы данных

### `users` — пользователи системы
| Поле | Тип | Описание |
|---|---|---|
| id | INT, PK | Уникальный идентификатор |
| login | VARCHAR(50), UNIQUE | Логин для входа |
| password | VARCHAR(255) | Хеш пароля (password_hash) |
| full_name | VARCHAR(100) | ФИО |
| phone | VARCHAR(20) | Телефон |
| email | VARCHAR(100) | Email |
| role | ENUM('user','admin') | Роль |
| created_at | TIMESTAMP | Дата регистрации |

### `orders` — заявки
| Поле | Тип | Описание |
|---|---|---|
| id | INT, PK | Уникальный идентификатор |
| user_id | INT, FK → users.id | Автор заявки |
| status_id | INT, FK → statuses.id | Текущий статус |
| title | VARCHAR(200) | Название |
| description | TEXT | Описание проблемы |
| category | VARCHAR(50) | Категория услуги |
| price | DECIMAL(10,2) | Стоимость |
| created_at | TIMESTAMP | Дата создания |
| updated_at | TIMESTAMP | Дата обновления |

### `statuses` — статусы заявок
| Поле | Тип | Описание |
|---|---|---|
| id | INT, PK | Уникальный идентификатор |
| name | VARCHAR(50), UNIQUE | Название статуса |
| description | VARCHAR(255) | Описание |
| color | VARCHAR(20) | Цвет бейджа |

**Предустановленные статусы:**
1. Новая (оранжевый)
2. В работе (синий)
3. Выполнена (зелёный)
4. Отклонена (красный)

## Связи
- `users 1 : N orders` — один пользователь может иметь много заявок
- `statuses 1 : N orders` — один статус применяется к многим заявкам

## Сценарии использования

### 1. Регистрация
- Валидация всех полей (логин, пароль, ФИО, телефон, email)
- Проверка уникальности логина (live-запрос + серверная проверка)
- Пароль хешируется через `password_hash()`
- Переход на страницу входа

### 2. Авторизация
- Проверка существования пользователя
- Проверка пароля через `password_verify()`
- Разделение ролей: пользователь → `user-dashboard.html`, админ → `admin-panel.html`
- Сессия на сервере + защита страниц

### 3. Работа пользователя
- Просмотр списка своих заявок
- Создание новой заявки с полями: название, описание, категория, цена
- Отображение статуса цветным бейджем

### 4. Работа администратора
- Просмотр всех заявок с данными пользователя
- Смена статуса через выпадающий список (4 варианта)
- Мгновенное сохранение в БД

## Установка и запуск

1. **Установить XAMPP** и MySQL Server.
2. **Поместить папку проекта** в `C:\xampp\htdocs\module1\`.
3. **Создать БД:** выполнить `database/schema.sql` в MySQL (через Workbench или phpMyAdmin).
4. **Настроить `database/config.php`:** указать логин, пароль, имя БД.
5. **Запустить Apache** в панели XAMPP (MySQL — отдельной службой).
6. **Открыть в браузере:** `http://localhost/module1/index.html`

## Модуль 3: Доработка БД, интеграция и анимации

Реализовано в рамках Модуля 3:

### Доработка базы данных
- **Таблица `order_status_history`** — полная история смены статусов заявок
- **Составные индексы** для фильтров админки (`idx_orders_user_status`, `idx_orders_status_created`, `idx_orders_category_created`)
- **FULLTEXT-индекс** для поиска по названию и описанию
- **CHECK-ограничения** — цена ≥ 0, название ≥ 3 символов, категория не пустая
- **Миграция `schema_v2.sql`** — применяется поверх базовой схемы без потери данных
- **Автозаполнение истории** для существующих заявок

### Интеграция фронт/бэк
- **История статусов для админа** — модальное окно с таймлайном: кто, когда, с какого на какой статус менял
- **История для пользователя** — модальное окно с таймлайном без имён админов (вариант Б)
- **Автозапись** «Заявка создана» при создании заявки
- **Транзакции** — обновление статуса + запись в историю атомарны
- **Защита от дублей** — если статус не изменился, новая запись не создаётся

### Микроанимации
- **Hover-эффекты**: блик на кнопках, поднятие карточек, подсветка строк таблицы
- **Toast с иконками и прогресс-баром** — автоскрытие с визуальной полоской
- **Skeleton-загрузка** списков заявок и таблицы админки
- **Спиннер на кнопках форм** при отправке
- **Плавные переходы**: fade-in карточек, плавное появление модалок, анимация смены пагинации
- **Пульсация активного статуса** в истории
- **Уважение `prefers-reduced-motion`** — доступность

### Адаптивность
- Проверено на **390×844** — весь функционал сохранён на мобильном
- Адаптивные фильтры, пагинация, модалки, toast
