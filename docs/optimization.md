# Оптимизация графики

## Цель
Уменьшить вес изображений слайдера без видимой потери качества,
чтобы ускорить загрузку главной страницы.

## Инструмент
**TinyPNG** — онлайн-сервис сжатия PNG/JPEG с сохранением визуального качества.

## Результаты

| Файл | До | После | Экономия |
|---|---|---|---|
| slide1.jpg | 360 КБ | 80 КБ | 78% |
| slide2.jpg | 367 КБ | 92 КБ | 75% |
| slide3.jpg | 633 КБ | 80 КБ | 87% |
| slide4.jpg | 302 КБ | 70 КБ | 77% |
| **Итого** | **1662 КБ** | **322 КБ** | **81%** |

## Как проверялось качество
- Визуальное сравнение «до/после» при 100% масштабе
- Разница незаметна невооружённым глазом
- Изображения корректно отображаются на всех устройствах (desktop + мобильный 390×844)

## Дополнительные оптимизации
- Формат JPG выбран для фотографий (лучшее сжатие по сравнению с PNG)
- Размер 1600×600 — оптимальная пропорция 8:3 для слайдера-карточки
- Шрифт Inter подключён локально (4 файла .ttf вместо загрузки через CDN)
- CSS использует переменные (`:root`) — единая палитра, меньше дублирования
